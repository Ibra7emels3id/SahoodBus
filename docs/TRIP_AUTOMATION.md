# التشغيل التلقائي للرحلات

تعمل مهمة `suhoud-trip-automation` كل دقيقة عبر نقطة `/api/scheduled/trip-automation` المنشورة. يُحفظ معرف المهمة في مجموعة `automationSettings` تحت الإعداد `trip-messaging` كي يمكن تتبعها أو إيقافها لاحقاً.

ترسل المهمة التذكير للحجز الواحد مرة واحدة فقط ضمن المدة المحددة قبل الرحلة، وترسل متابعة واحدة بعد الرحلة المنطلقة/المغلقة ضمن المدة المحددة. يعتمد منع التكرار على حقل `category` داخل سجل `whatsappMessages`.

إذا سجّل Wasender حالة `rate_limited`، لا يعتبر النظام هذه محاولة مكتملة؛ يعيد المحاولة في الدورة التالية بدلاً من فقد الرسالة، وهو مناسب خصوصاً لحد التجربة المؤقت.

يدير المدير التوقيت والرابط من صفحة «واتساب والرسائل». الإعداد الافتراضي هو تذكير قبل 120 دقيقة ومتابعة بعد 360 دقيقة. لا تُرسل الرسائل عندما تكون جلسة Wasender غير متصلة.

تتعامل رسالة المتابعة مع الرد `1` كتقييم إيجابي وترسل رابط Google Maps المحفوظ، وتتعامل مع `2` أو نص المشكلة كملاحظة تحتاج تواصلاً من الفريق، مع رسالة اعتذار آلية.
